## 1. 한 줄 요약

추론 효율성을 최우선으로 고려하는 관점에서 Mamba-2의 상태 공간 모델 재귀식을 세 방향으로 개선합니다. 첫째, 지수-사다리꼴 이산화를 통해 표현력이 확장된 재귀식을 도출합니다. 둘째, 복소수 상태 전이를 도입하여 기존 선형 모델이 해결하지 못하던 상태 추적 과제를 해결합니다. 셋째, 다중입력-다중출력 MIMO 구조를 적용하여 은닉 상태 크기의 증가 없이 디코딩 연산 처리량을 확장했습니다. 이를 통해 1.5B 파라미터 규모에서 Mamba-3 MIMO는 Transformer 대비 2.2포인트, Mamba-2 대비 1.9포인트 향상된 평균 정확도를 달성합니다.

## 2. 연구 배경 및 동기

### 2.1. 문제 정의

추론 단계에서의 연산량 확장인 Test-time Compute Scaling이 대규모 언어 모델 성능 향상의 핵심 요소로 부상하면서, 모델의 추론 효율성이 아키텍처 설계의 중심 과제가 되었습니다. 기존 Transformer는 KV 캐시로 인한 메모리 사용량 증가와 자기 어텐션의 2차 연산 복잡도로 인해 긴 시퀀스를 처리할 때 큰 비용이 발생합니다. 이에 따라 일정한 메모리와 시퀀스 길이에 비례하는 선형 시간 복잡도로 동작하는 상태 공간 모델과 선형 어텐션 아키텍처가 주목받고 있습니다.

### 2.2. 기존 방법의 한계 및 이론적 배경

기존 선형 시퀀스 모델들은 연산 효율성을 확보한 반면 표현력과 기능 측면에서 명확한 한계를 보였습니다:

| 한계 영역 | 현상 | 원인 메커니즘 |
|-----------|------|---------------|
| 표현력 저하 | Mamba-2가 Mamba-1 대비 추론 매칭 성능에서 열세를 보입니다 | 이산화 과정에서 상태 입력 적분을 1차 오일러 근사에 의존하여 수치 정확도가 떨어집니다 |
| 상태 추적 실패 | 패리티 판별이나 모듈러 산술과 같은 이산 상태 추적 과제를 해결하지 못합니다 | 상태 전이 행렬을 음의 실수 스칼라로 제한하여 상태 벡터를 회전시키는 동역학을 표현할 수 없습니다 |
| 디코딩 하드웨어 비효율성 | 이론적 선형 복잡도에도 불구하고 토큰 생성 시 GPU 연산 자원이 유휴 상태로 남습니다 | 단일입력-단일출력 구조로 인해 디코딩 단계의 산술 강도가 낮아 메모리 대역폭 병목이 발생합니다 |

이러한 한계가 발생하는 구체적인 원인은 다음과 같습니다.

#### 상태 전이 행렬의 음의 실수 제약과 회전 동역학 부재

상태 전이 행렬 $A$는 상태 공간 모델 내부에서 이전 은닉 상태 $h_{t-1}$이 다음 은닉 상태 $h_t$로 전이될 때 정보의 감쇠 비율을 결정하는 핵심 파라미터 텐서입니다.

Mamba-1과 Mamba-2는 수치적 발산을 막고 안정적인 학습을 유지하기 위해 상태 전이 행렬 $A$의 고유값을 0보다 작은 음의 실수 스칼라로 제한했습니다. 연속 미분방정식의 해는 $\exp(At)$ 형태를 띠므로, $A$가 양수이면 시간에 따라 상태가 무한히 발산하지만 $A$가 음수이면 $\exp(At)$가 0과 1 사이의 값으로 수렴하여 시스템이 안정적인 지수 감쇠를 유지하기 때문입니다.

그러나 상태 전이 행렬을 순수 실수로 제한하면 은닉 상태 벡터의 방향이 고정된 채 시간에 따라 크기만 줄어드는 단순 감쇠만 가능해집니다. 반면 회전 동역학은 복소수 오일러 공식 $e^{i\theta} = \cos \theta + i \sin \theta$에 기반하여 상태 벡터를 특정 각도 $\theta$만큼 회전시키는 전이 방식입니다. 상태 벡터가 회전하면 상태 크기를 줄이지 않고도 위상, 주기, 토큰 출현 횟수와 같은 정보를 회전 각도에 누적하여 보존할 수 있습니다.

이러한 회전 동역학의 부재는 엄밀한 상태 추적 실패로 직결됩니다. 상태 추적은 과거 문맥을 대략적으로 요약하는 일반적인 텍스트 생성과 달리, 시스템의 이산적인 내부 상태를 정확히 기억하고 갱신하는 오토마타 추론 능력입니다. 예를 들어 비트 시퀀스에서 1이 홀수 번 등장했는지 짝수 번 등장했는지를 판별하는 패리티 연산이나 특정 주기로 순환하는 모듈러 연산이 이에 해당합니다.

패리티 판별을 정확히 수행하려면 1이 입력될 때마다 상태 벡터가 180도 회전하여 부호를 반전시켜야 합니다. 하지만 실수 감쇠만 존재하는 Mamba-1과 Mamba-2는 상태 부호를 반전시킬 수 없으며, 시퀀스가 길어질수록 과거 정보가 0으로 감쇠되어 사라집니다. 그 결과 과거 입력을 기억하고 추론해야 하는 상태 공간 모델의 본래 설계 목표와 달리, 엄밀한 알고리즘 과제에서 무작위 추측 수준의 성능을 보였습니다.

#### 지수-오일러 이산화의 휴리스틱 근사

연속 시간 미분방정식으로 정의된 상태 공간 모델을 텍스트 토큰과 같은 이산 시퀀스에 적용하려면 이산 재귀식으로 변환하는 이산화 과정이 필요합니다. 전통적인 상태 공간 모델은 지수 적분을 정밀하게 변환하는 영차 유지 기법을 사용했습니다.

하지만 Mamba-1과 Mamba-2는 입력에 따라 스텝 사이즈가 변하는 시간 변동 시스템의 연산 복잡도를 줄이기 위해, 실제 구현체에서 상태 입력 적분을 단순 오일러 규칙 기반의 지수-오일러 방식으로 대체했습니다. 이는 연속 적분의 수치 해석적 오차 유도나 수학적 정당성 검증 없이 계산 편의만을 위해 임의로 채택한 근사였으므로 이론적 정당성이 부족했습니다.

#### 단일입력-단일출력 구조와 메모리 대역폭 병목

자가회귀 디코딩은 언어 모델이 글을 작성할 때 이전에 자신이 생성한 토큰을 다음 스텝의 입력으로 전달받아 한 번에 한 토큰씩 순차적으로 문장을 완성해 나가는 생성 방식입니다.

직전 토큰이 생성되어야만 다음 토큰을 계산할 수 있는 자가회귀 특성상, 시간 축으로는 어쩔 수 없이 토큰을 하나씩 순차 처리해야 합니다. 이때 기존 Mamba-2는 각 채널이나 헤드에서 한 번에 1개의 입력 토큰을 받아 1개의 출력을 내보내는 단일입력-단일출력 SISO 구조를 사용합니다.

이 방식에서는 토큰을 하나 생성할 때마다 GPU VRAM에서 과거의 거대한 은닉 상태 텐서를 불러와 입력 토큰 1개와 단순 벡터 외적을 수행한 뒤 다시 VRAM에 저장합니다. 최신 GPU의 연산 코어는 수천 개의 텐서 코어가 대규모 행렬곱을 병렬 처리할 수 있을 만큼 강력하지만, VRAM에서 데이터를 읽고 쓰는 메모리 대역폭 속도는 상대적으로 매우 느립니다.

단일입력-단일출력 구조에서는 대용량 은닉 상태 텐서를 메모리에서 통째로 읽어왔음에도 수행하는 연산량이 토큰 1개에 대한 단순 벡터 곱셈에 불과하므로, 읽어온 데이터 바이트당 연산 횟수인 산술 강도가 약 2.5 ops/byte로 극히 낮아집니다. 결과적으로 강력한 GPU 연산 코어의 대부분이 메모리 입출력이 끝나기를 기다리며 유휴 상태로 낭비되는 메모리 대역폭 병목이 발생합니다.

### 2.3. 핵심 기여

- 지수-사다리꼴 이산화 유도: 시간 변동 상태 공간 모델을 위한 일반화 이산화 프레임워크를 수립하여 기존 Mamba의 오일러 근사를 이론적으로 규명하고, 2차 수치 정확도를 갖는 사다리꼴 적분 기반 3항 재귀식을 도출합니다.
- 복소수 상태 공간 및 데이터 종속 RoPE 도출: 복소수 상태 전이가 데이터 종속 Rotary Position Embedding을 Key와 Query 성분에 적용하는 것과 동치임을 증명하여, 회전 동역학을 확보하고 패리티 및 모듈러 산술 과제를 완벽히 해결합니다.
- 다중입력-다중출력 구조 도입: 디코딩 단계의 외적 연산을 행렬곱 연산으로 확장하여 상태 크기 증가 없이 산술 강도를 높입니다. 이를 통해 실제 추론 지연시간의 증가 없이 디코딩 연산량을 최대 4배 확장합니다.
- 짧은 인과 합성곱 제거: 지수-사다리꼴 이산화가 유도하는 내부 암묵적 합성곱과 바이어스의 시너지를 통해, 기존 선형 모델의 필수 구성 요소로 여겨졌던 외부 짧은 인과 합성곱 모듈을 제거합니다.

## 3. 제안 방법: Mamba-3 프레임워크

### 3.1. Mamba-2의 상태 공간 재귀식

연속 시간 상태 공간 모델의 미분방정식은 다음과 같은 형태를 갖습니다:

$$h'(t) = A(t) h(t) + B(t) x(t), \quad y(t) = C(t)^T h(t)$$

여기서 입력 신호 $x(t)$는 모델 외부에서 입력되는 실제 데이터 토큰 신호입니다. $A(t)$와 $B(t)$는 외부 입력 데이터가 아니며, 시스템 내부 은닉 상태 $h(t)$가 자체적으로 감쇠하는 비율과 새로운 입력 $x(t)$를 반영하는 가중치를 조절하는 내부 제어 파라미터 텐서입니다. 최종 출력 $y(t)$는 숨겨진 은닉 상태 $h(t)$에 추출 필터 $C(t)$를 곱하여 읽어낸 단일 출력값입니다.

Mamba-2는 이 연속 시스템을 이산화하여 다음 재귀식으로 변환합니다:

$$h_t = \alpha_t h_{t-1} + \gamma_t B_t x_t, \quad y_t = C_t^T h_t$$

이 재귀식은 매 시점 노트를 정리하는 과정과 유사합니다. 이전 상태 $h_{t-1}$에 지수 감쇠 계수 $\alpha_t = \exp(\Delta_t A_t)$를 곱하여 과거 메모의 일부를 지우고, 현재 입력 $x_t$에 입력 가중치 $\gamma_t = \Delta_t$를 곱하여 새로운 메모를 추가합니다.

이 순차적 재귀식을 병렬 학습 시 한 번에 계산하기 위해 구조화 상태 공간 SSD 프레임워크에서는 시간 감쇠 마스크 행렬 $L$을 도입합니다:

$$Y = (L \odot CB^T) X$$

마스크 행렬 $L$은 대각선 위쪽이 전부 0인 하삼각 행렬입니다. 대각선 위쪽을 0으로 차단함으로써 과거 시점이 미래 토큰을 미리 참조하지 못하도록 인과성을 보장합니다.

순차 재귀식이 어떻게 삼각 행렬 $L$로 변환되는지는 시점 1, 2, 3의 3개 토큰 시퀀스 예시로 쉽게 이해할 수 있습니다:
- 시점 1의 출력: $y_1 = \gamma_1 x_1$
- 시점 2의 출력: $y_2 = \alpha_2 y_1 + \gamma_2 x_2 = \alpha_2 \gamma_1 x_1 + \gamma_2 x_2$
- 시점 3의 출력: $y_3 = \alpha_3 y_2 + \gamma_3 x_3 = \alpha_3 \alpha_2 \gamma_1 x_1 + \alpha_3 \gamma_2 x_2 + \gamma_3 x_3$

이를 행렬 곱셈 형태로 묶으면 다음과 같은 3×3 하삼각 마스크 행렬 $L$이 유도됩니다:

$$\begin{bmatrix} y_1 \\ y_2 \\ y_3 \end{bmatrix} = \begin{bmatrix} \gamma_1 & 0 & 0 \\ \alpha_2 \gamma_1 & \gamma_2 & 0 \\ \alpha_3 \alpha_2 \gamma_1 & \alpha_3 \gamma_2 & \gamma_3 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}$$

이 마스크 행렬 $L$의 각 행은 정보 감쇠 게이트 역할을 완벽히 수행합니다:
- 1행: 현재 시점 $x_1$만 $\gamma_1$ 가중치로 반영되며, 아직 오지 않은 미래 입력 $x_2$와 $x_3$는 0으로 완전히 차단됩니다.
- 2행: 과거 입력 $x_1$은 1스텝 감쇠 계수 $\alpha_2$가 곱해져 크기가 줄어든 상태로 반영되고, 현재 입력 $x_2$는 온전히 더해집니다.
- 3행: 2스텝 전의 과거 입력 $x_1$은 두 번의 감쇠 계수가 연쇄 곱해진 $\alpha_3 \alpha_2$만큼 희미하게 반영되고, 1스텝 전의 $x_2$는 $\alpha_3$만큼 감쇠되어 반영되며, 현재 입력 $x_3$는 온전히 반영됩니다.

결과적으로 마스크 행렬 $L$을 사용하면, 매 시점 루프를 돌며 과거 상태를 감쇠시키던 순차 연산을 단 한 번의 GPU 병렬 행렬곱으로 정확하게 동일하게 처리할 수 있습니다.

### 3.2. 지수-사다리꼴 이산화

![지수-사다리꼴 이산화 개념도](/images/mamba3/_page_3_Figure_0.jpeg)

*Figure 1: (좌) 지수-사다리꼴 규칙이 유도하는 구조화 마스크는 감쇠 행렬과 2-밴드 합성곱 행렬의 곱으로 구성됩니다. (우) 오일러 방식과 사다리꼴 적분 근사의 비교.*

이산화 기법에서 수치 적분 오차는 스텝 크기 $\Delta_t$의 승수에 직접적인 영향을 받습니다. 연속 데이터 구간을 잘라 적분할 때 스텝 크기 $\Delta_t$는 보통 0.1 이하의 작은 값이므로, 오차의 승수가 높을수록 적분 과정에서 누적되는 오차가 급격히 줄어듭니다.

Mamba-1과 Mamba-2에 적용된 지수-오일러 방식은 적분 구간을 직사각형 형태로 단순하게 잘라 계산하는 1차 근사 방식입니다. 이 방식은 잔여 오차가 스텝 크기의 제곱인 $O(\Delta_t^2)$ 수준으로 누적되어 수치 정밀도에 한계가 있었습니다. 예를 들어 스텝 크기가 0.1이면 0.01 단위의 오차가 남습니다.

반면 Mamba-3가 제안하는 지수-사다리꼴 방식은 구간의 양 끝점을 직선으로 이어 사다리꼴 형태로 곡선을 촘촘하게 메우는 2차 정확도 방식입니다. 이 방식은 잔여 오차가 스텝 크기의 세제곱인 $O(\Delta_t^3)$으로 급감합니다. 동일하게 스텝 크기가 0.1인 상황에서 오차가 0.001로 줄어들어 오차를 10분의 1 이하로 축소시키므로 수치 해석적 정밀도를 크게 향상시킵니다.

Mamba-3가 도출한 지수-사다리꼴 이산화 재귀식은 다음과 같습니다:

$$h_t = \alpha_t h_{t-1} + \beta_t B_{t-1} x_{t-1} + \gamma_t B_t x_t$$

여기서 $\alpha_t = \exp(\Delta_t A_t)$, $\beta_t = (1 - \lambda_t) \Delta_t \exp(\Delta_t A_t)$, $\gamma_t = \lambda_t \Delta_t$이며, $\lambda_t \in [0, 1]$는 데이터 종속 스칼라입니다.

Mamba-2가 현재 입력 $x_t$만으로 상태를 갱신하는 반면, Mamba-3는 과거 입력 항 $\beta_t B_{t-1} x_{t-1}$을 추가하여 과거 입력 $x_{t-1}$과 현재 입력 $x_t$를 비율에 따라 함께 섞어 상태를 갱신합니다. 연속된 두 토큰 입력을 결합하는 구조는 재귀식 내부에서 너비 2의 데이터 종속 인과 합성곱을 자연스럽게 수행함을 의미합니다. 따라서 Mamba-2가 외부 모듈에 의존했던 짧은 인과 합성곱 레이어를 Mamba-3에서는 재귀식 내부로 완전히 흡수할 수 있습니다.

구조화 상태 공간 병렬 행렬 형태에서 Mamba-3의 마스크 $L$은 1-준분리 행렬과 2-밴드 행렬의 곱으로 표현됩니다. 1-준분리 행렬은 삼각 성분들이 과거로 갈수록 $\alpha_t$의 연쇄 감쇠 곱으로 형성되는 삼각 행렬이며, 2-밴드 행렬은 주대각선과 그 아래 대각선에만 값이 존재하는 2줄짜리 밴드 행렬로 연속 토큰 간의 믹싱을 담당합니다. Mamba-2는 과거 입력 항이 없어 주대각선만 존재하는 대각 행렬이었으나, Mamba-3는 대각선을 하나 더 추가하여 감쇠와 내부 합성곱을 동시에 병렬 행렬곱으로 표현합니다.

### 3.3. 복소수 상태 공간 모델 및 RoPE Trick

기존 상태 공간 모델은 패리티 판별이나 모듈러 연산과 같은 이산 상태를 엄밀하게 추적하지 못하는 치명적인 한계가 있었습니다. Mamba-3는 이를 해결하기 위해 복소수 상태 전이를 도입하고, 연산 효율성을 유지하기 위한 RoPE Trick을 제시합니다.

#### 실수 감쇠와 복소수 회전의 직관적 원리

실수와 복소수가 상태를 다루는 방식의 차이는 수직선과 2차원 시계 바늘의 비유로 쉽게 이해할 수 있습니다:

- 실수 감쇠: 1차원 수직선 위에 놓인 고무줄의 길이와 같습니다. 이전 상태에 0.9와 같은 음의 실수 감쇠 계수를 반복해서 곱하면, 점은 방향을 바꾸지 못한 채 0을 향해 크기만 줄어들다가 결국 사라집니다. 아무리 다른 실수를 곱해도 크기를 수축시키는 것 외에는 할 수 없습니다.
- 복소수 회전: 수직선에 허수 $i$ 축을 하나 세워 2차원 평면을 만들고, 상태 벡터를 시계 바늘처럼 바라보는 것입니다. 복소수 오일러 공식 $e^{i\theta} = \cos \theta + i \sin \theta$에 의해, 복소수를 곱하는 연산은 벡터의 길이는 그대로 둔 채 각도 $\theta$만큼 방향을 찰칵 돌려주는 회전 연산과 같습니다.

예를 들어 켜짐과 꺼짐의 홀짝을 판별하는 패리티 판별의 경우, 입력이 들어올 때마다 바늘을 180도씩 돌리기만 하면 됩니다:
- 0번 입력: 12시 방향인 짝수 상태
- 1번 입력: 6시 방향인 홀수 상태로 부호 반전
- 2번 입력: 다시 12시 방향인 짝수 상태

바늘의 길이가 닳아서 없어지지 않고 오직 바늘이 가리키는 회전 각도로 정보를 저장하므로, 시퀀스가 아무리 길어져도 상태가 감쇠 소멸하지 않고 완벽하게 기억됩니다.

#### 복소수 상태 공간 모델의 수식화

Mamba-3는 연속 시간 시스템의 대각 전이 행렬에 복소수 성분 $i \theta(t)$를 추가하여 다음과 같이 정의합니다:

$$h'(t) = \text{Diag}(A(t) + i \theta(t)) h(t) + (B(t) + i \hat{B}(t)) x(t)$$

여기서 $A(t)$는 기존의 실수 감쇠율을 조절하고, $\theta(t)$는 상태가 회전하는 각속도를 결정합니다.

이 연속 미분방정식을 이산화하면, 2개의 실수 차원이 묶여 2×2 회전 행렬 $R_t$을 형성하는 블록 대각 전이 행렬로 변환됩니다:

$$h_t = \exp(\Delta_t A_t) R_t h_{t-1} + \Delta_t B_t x_t$$

여기서 회전 행렬 $R_t$는 2차원 평면에서 각도 $\Delta_t \theta_t$만큼 좌표를 회전시키는 2×2 행렬입니다:

$$R_t = \begin{bmatrix} \cos(\Delta_t \theta_t) & -\sin(\Delta_t \theta_t) \\ \sin(\Delta_t \theta_t) & \cos(\Delta_t \theta_t) \end{bmatrix}$$

#### RoPE Trick을 통한 연산 오버헤드 해결

복소수 회전 행렬은 강력하지만 치명적인 연산 부담이 따릅니다. 은닉 상태 $h_t$는 수만 개의 성분으로 이루어진 거대한 텐서인데, 매 스텝마다 거대한 상태 전체에 복소수 회전 행렬을 직접 곱하면 실수 곱셈보다 계산량이 4배 늘어나고 메모리 지연시간이 폭발하게 됩니다.

Mamba-3는 이 난제를 RoPE Trick이라는 수학적 동치 변환으로 해결합니다:
- 핵심 아이디어: 거대한 은닉 상태 텐서 $h_t$ 전체를 복소수로 회전시키는 대신, 상태 자체는 가벼운 실수 감쇠 연산만 하도록 그대로 둡니다. 대신 상태에 데이터를 넣을 때 쓰이는 Key 성분인 $B_t$와 꺼내 읽을 때 쓰이는 Query 성분인 $C_t$에만 회전 각도를 미리 적용해 줍니다.
- 수학적 동치성: 수식을 풀어서 전개해 보면, 상태 $h_t$를 매 시점 회전시킨 결과와, 상태는 가만히 두고 $B_t$와 $C_t$에 누적 회전 행렬을 곱해 준 결과가 정확히 일치합니다:

$$h_t = \exp(\Delta_t A_t) h_{t-1} + \left(\prod_{j=1}^t R_j^T\right) \Delta_t B_t x_t, \quad y_t = \left[\left(\prod_{j=1}^t R_j^T\right) C_t\right]^T h_t$$

- Transformer 기술과의 결합: Transformer 아키텍처는 토큰 위치에 따라 Query와 Key를 회전시키는 Rotary Position Embedding RoPE라는 초고속 GPU 커널을 이미 갖추고 있습니다. Mamba-3는 이 표준 RoPE 커널을 그대로 가져와, 고정된 위치 각도 대신 현재 입력 데이터로부터 생성된 회전 각도 $\theta_t$를 Key와 Query에 적용합니다.

이 방식을 통해 Mamba-3는 복소수 상태 공간 모델의 뛰어난 회전 기억 능력과 패리티 판별 100% 달성 능력을 온전히 얻으면서도, 실수 모델과 거의 동일한 초고속 연산 속도를 유지합니다.

### 3.4. 다중입력-다중출력 상태 공간 모델

![Mamba-2와 Mamba-3 아키텍처 비교](/images/mamba3/_page_10_Picture_0.jpeg)

*Figure 2: Mamba-2와 Mamba-3 아키텍처 비교. 지수-사다리꼴 이산화, 데이터 종속 RoPE 임베딩, MIMO 프로젝션, 정규화, 학습 가능한 바이어스 등의 구성 변화를 보여줍니다.*

기존 단일입력-단일출력 상태 공간 모델은 디코딩 단계에서 산술 강도가 약 2.5 ops/byte로 극히 낮아 메모리 대역폭 병목이 발생했습니다. 최신 GPU의 텐서 코어는 행렬-행렬 곱셈 Matmul을 수행할 때 최대 수백 ops/byte의 연산 성능을 발휘하도록 최적화되어 있으나, 기존 구조는 토큰 1개당 단순 벡터 외적 연산만 수행하므로 대부분의 연산 유닛이 놀게 됩니다.

이 문제를 해결하기 위해 Mamba-3는 자가회귀의 순차적 토큰 생성 루프는 유지하되, 내부 채널 차원에 랭크 $R$의 다중 경로를 부여하는 다중입력-다중출력 MIMO 구조를 도입합니다:

- 입력 신호 차원 확장: $x_t \in \mathbb{R}^P \to x_t \in \mathbb{R}^{P \times R}$
- 상태 입력 프로젝션 확장: $B_t \in \mathbb{R}^N \to B_t \in \mathbb{R}^{N \times R}$
- 상태 출력 프로젝션 확장: $C_t \in \mathbb{R}^N \to C_t \in \mathbb{R}^{N \times R}$

은닉 상태 $h_t \in \mathbb{R}^{N \times P}$의 메모리 크기는 그대로 유지되므로 메모리 전송량 증가는 미미합니다. 반면 상태 입력과의 연산이 단순 벡터 외적에서 $R$차원의 소형 행렬-행렬 곱셈으로 격상되어 FLOPs가 $R$배 증가합니다. 이 추가 연산은 GPU 텐서 코어에서 메모리 입출력과 완전히 병렬로 수행되므로 실제 추론 지연시간은 거의 늘어나지 않습니다.

| 항목 | SISO 단일입력-단일출력 | MIMO 다중입력-다중출력 Rank R |
|------|--------------------------|-----------------------------------|
| 산술 강도 | 약 2.5 ops/byte | 약 2.5 × R ops/byte |
| 디코딩 FLOPs | $5NP - P$ | $4NPR + NP - PR$ |
| 은닉 상태 크기 | $N \times P$ | $N \times P$ 동일 |

학습 단계에서 MIMO 구조는 $R^2$개의 SISO 구조로 분해되지만, 청크 알고리즘에서 청크 크기를 $C / R$로 조정하면 학습 비용 증가를 $R$배 이내로 제한할 수 있습니다. 실제로 랭크 4 설정에서 MIMO 커널은 SISO 대비 약 2배 수준의 시간만 소요됩니다.

파라미터 효율성을 위해 Mamba-3는 $B$와 $C$ 프로젝션에만 랭크 $R$을 직접 적용하고, 나머지 프로젝션은 기존 SISO 차원에 학습 가능한 데이터 비종속 벡터를 곱해 원소별 스케일링을 적용했습니다. 이를 통해 파라미터 증가를 최소화하고, MLP 내부 차원을 소폭 축소하여 전체 모델 파라미터 수를 기존 모델과 동일하게 유지했습니다.

### 3.5. 아키텍처 세부 구성

Mamba-3의 전체 아키텍처는 Llama 설계를 따라 Mamba-3 블록과 SwiGLU 블록을 Pre-Norm 방식으로 교대 배치합니다. 기존 Mamba-2 블록 대비 핵심 변경 사항은 다음과 같습니다:

- 갱신된 재귀식: 구조화 상태 공간 레이어를 RoPE Trick이 적용된 복소수 지수-사다리꼴 재귀식으로 교체했습니다. $A$의 실수부는 상태 공간 엔진에서 처리하고 허수부는 RoPE Trick으로 연산합니다.
- 프로젝션 정규화: $B$와 $C$ 프로젝션 뒤에 RMSNorm을 추가하여 학습을 안정화했습니다. 이를 통해 Mamba-2에서 안정성을 위해 사용하던 게이트 후단 RMSNorm을 제거할 수 있었습니다.
- 학습 가능한 바이어스: $B$와 $C$ 정규화 뒤에 학습 가능한 헤드별 및 채널별 바이어스를 추가했습니다. 이 데이터 비종속 성분이 합성곱과 유사한 동작을 유도하여, 지수-사다리꼴 이산화와 시너지를 이루며 외부 짧은 인과 합성곱을 완전히 불필요하게 만듭니다.

### 4.5. 검색 능력 및 하이브리드 모델

Mamba-3는 연관 회상과 질의응답에서 경쟁력 있는 성능을 보이지만, 반정형 및 비정형 데이터 추출에서는 Transformer에 미치지 못합니다. 이는 고정 크기 상태의 본질적 한계이며, 자기 어텐션 레이어와 5:1 비율로 교대 배치하는 하이브리드 아키텍처로 보완할 수 있습니다. 하이브리드 모델은 순수 Transformer를 능가하며, 게이트 전단 그룹 RMSNorm 추가 시 길이 일반화 검색 능력이 크게 향상됩니다.

## 5. 핵심 기여 정리

1. 지수-사다리꼴 이산화 프레임워크: 시간 변동 상태 공간 모델에 대한 체계적 이산화 방법론을 제시합니다. Mamba-1과 Mamba-2의 이산화를 지수-오일러 방식으로 형식화하여 이론적으로 정당화하고, 이를 2차 정확도의 지수-사다리꼴 방식으로 확장합니다. 3항 재귀식이 상태 입력에 대한 너비 2의 암묵적 합성곱과 동치라는 점을 병렬 행렬 형태로 증명하며, 이 내부 합성곱과 바이어스의 시너지가 기존에 필수적이라 여겨졌던 외부 짧은 인과 합성곱을 불필요하게 만들어 아키텍처를 단순화합니다.

2. 복소수 상태 전이와 데이터 종속 RoPE: 복소수 상태 공간 모델이 이산화 후 스칼라 감쇠와 2×2 회전 행렬의 블록 대각 전이와 동치임을 증명하고, 이를 바닐라 모델에 데이터 종속 RoPE를 Key와 Query에 적용하는 것으로 재해석합니다. 기존 RoPE의 데이터 비종속 고정 주파수 회전과 달리, Mamba-3의 회전 각도는 입력 데이터로부터 직접 생성되어 회전 동역학을 학습할 수 있습니다. 이를 통해 기존 모델들이 무작위 추측 수준에 머물렀던 패리티, 모듈러 산술 등 상태 추적 과제에서 100%에 근접한 정확도를 달성합니다.

3. MIMO를 통한 추론 효율성과 모델링 성능 동시 향상: 디코딩 단계의 낮은 산술 강도 문제를 해결하기 위해, 단일입력-단일출력 재귀식을 다중입력-다중출력으로 확장합니다. 상태 크기는 유지하면서 랭크 $R$ 차원을 추가하여 디코딩 연산량을 $R$배 증가시키되, 추가 연산이 GPU 텐서 코어로 메모리 입출력과 중첩되므로 실제 추론 지연시간은 거의 증가하지 않습니다. 440M 규모에서 Mamba-3 MIMO는 Mamba-2 대비 절반의 상태 크기로 동등한 퍼플렉시티를 달성하여 더 빠른 추론 속도로 동일한 성능을 제공합니다.

4. 상태 공간 모델 관점 고유의 방법론적 혁신: 이산화, 복소수 전이, MIMO의 세 가지 핵심 기여는 상태 공간 모델 관점에서 자연스럽게 도출되지만, 선형 어텐션이나 테스트 타임 학습 관점에서는 직관적이지 않다는 점이 이론적으로 의미 있습니다. 이산화는 연관 메모리 프레임워크에 존재하지 않고, 복소수 값은 L2 정규화 계수로서 해석하기 어려우며, MIMO는 선형 어텐션 프레임워크에 대응물이 없습니다. 이는 상태 공간 모델 관점이 선형 시퀀스 모델 개선에 고유한 설계 공간을 열어줌을 보여줍니다.
